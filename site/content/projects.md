\# 프로젝트 소개



프로그래밍을 학습하면서 직접 구현한 알고리즘과 웹 개발 실습을 정리한 페이지입니다.



\## 프로젝트 1. Python 정렬 알고리즘 구현



\*\*사용 기술:\*\* Python



\*\*프로젝트 설명:\*\* 선택 정렬과 병합 정렬 알고리즘의 동작 원리를 학습하고 Python으로 구현했습니다.



\*\*주요 학습 내용:\*\*

\- 선택 정렬의 최소값 탐색 및 교환 과정

\- 병합 정렬의 분할과 병합 과정

\- 알고리즘별 비교 횟수와 시간 복잡도 분석



\## 프로젝트 2. Python 자료구조 구현



\*\*사용 기술:\*\* Python



\*\*프로젝트 설명:\*\* 이진 탐색 트리(BST), 힙, 연결 리스트 등의 자료구조를 구현하고 데이터의 삽입과 삭제 과정을 학습했습니다.



\*\*주요 학습 내용:\*\*

\- 이진 탐색 트리의 탐색, 삽입, 삭제

\- 최소 힙의 `push`, `pop` 연산

\- 연결 리스트의 노드 연결 및 삭제



\## 프로젝트 3. HTML 자기소개 페이지 제작



\*\*사용 기술:\*\* HTML



\*\*프로젝트 설명:\*\* HTML의 기본 태그를 활용해 자기소개 웹페이지를 제작했습니다.



\*\*주요 학습 내용:\*\*

\- 제목과 문단 작성

\- 목록 및 이미지 삽입

\- 외부 웹사이트 링크 연결
